# Roadmap

## Phase 1 - macOS desktop MVP

- Basic libprojectM renderer
- Preset folder import
- Playlist editor
- Timing controls
- Fullscreen
- Mic/demo audio input

## Phase 2 - desktop polish

- Windows/Linux builds
- Better preset metadata
- Search/filter/favourites
- Import zip packs
- Export/share playlists
- Crash-safe preset loading
- Bad preset quarantine

## Phase 3 - Android

- Android audio capture path
- Touch UI
- Battery/performance mode
- Keep-screen-awake party mode
- Scoped storage/import handling

## Phase 4 - iOS

- iOS audio capture constraints
- Metal/OpenGL compatibility investigation
- App Store policy review

## Phase 5 - curated preset pack

- Only include presets with explicit permission or clear licence
- Author attribution
- Takedown process
- Optional community submission process
